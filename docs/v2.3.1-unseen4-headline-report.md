# v2.3.1 independent unseen headline evaluation

## Method

- 50 previously unused German news headlines were frozen from NDR and rbb24.
- Editorial labels were assigned before running v2.3.1.
- The frozen v2.3.1 rules were not changed after labeling.
- This is explicitly a **headline-only** test. English collection notes are retained for audit context but excluded from scoring.
- No publishing node or paid AI node was executed.

## Result

| Metric | Value |
|---|---:|
| Accuracy | 54.00% |
| Precision | 94.12% |
| Recall | 42.11% |
| F1 | 58.18% |
| False positives | 1 |
| False negatives | 22 |
| Importance MAE | 1.42 |

## Interpretation

The high precision indicates that v2.3.1 rarely accepts an irrelevant headline. The low recall is a release blocker: many relevant headlines do not contain the narrow deterministic vocabulary required by the current rules. Missed areas include infrastructure, public transport, public health, climate impacts, cyber incidents, drinking-water warnings, housing contamination, parliamentary decisions, and local security events.

The earlier 98% tuning result must therefore not be treated as evidence of generalization. Version v2.3.1 should remain on the feature branch and must not be merged into `main` as a production-ready ranking release.

## Recommended next iteration

Build v2.4 around broader semantic evidence and calibrated fallback rules rather than adding keywords for the 22 individual misses. Evaluate full German title-plus-description inputs on a fifth frozen set before any merge decision.
